# Testjournal

Hier steht jeder Test, den wir ausprobieren, mit Ergebnis. Das Journal ist die Grundlage für den späteren 90-Tage-Plan: Nur was hier steht, können wir später gezielt wiederholen, an Creator geben und mit Werbung skalieren. Claude legt Tests mit `/test-eintragen` an und trägt die Zahlen nach.

Regeln für gute Tests:
- Hypothese **vorher** aufschreiben.
- Nur **eine** Sache ändern (z. B. nur den Hook).
- Erfolgskriterium vorher festlegen.
- Zahlen nach 48 Stunden und nach 7 Tagen eintragen.

## Tests im Detail

Vorlage für einen Test (Claude kopiert sie für jeden neuen Test):

```
### T-001: Kurztitel

- Datum:
- Autor:
- Konto / Plattform / Sprache / Format:
- Hypothese: Wenn wir …, dann …, weil …
- Was wird variiert: (nur eine Sache)
- Was bleibt gleich:
- Erfolgskriterium: (z. B. „Ø Wiedergabe über 60 %“ oder „doppelt so viele Saves wie unser Schnitt“)
- Hook:
- Link zum Post:
- Zahlen nach 48 Stunden: Aufrufe / Ø Wiedergabe / Likes / Kommentare / Shares / Saves / Profilaufrufe / Link-Klicks
- Zahlen nach 7 Tagen: Aufrufe / Ø Wiedergabe / Likes / Kommentare / Shares / Saves / Profilaufrufe / Link-Klicks
- Erkenntnis in einem Satz:
- Nächster Schritt: wiederholen / verwerfen / skalieren
```

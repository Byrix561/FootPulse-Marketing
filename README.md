# FootPulse Marketing

Das ist der gemeinsame Arbeitsplatz für Marketing und Content von FootPulse. FootPulse bewertet Fußballspieler nach ihrer echten Leistung und erklärt jede Bewertung (Karten im FIFA-Stil, Team der Woche). Website und Warteliste: footpulse.org.

## Für wen

- **Burhan**: Gründer und Owner. Pflegt den Branch `main` und die festen Regeln.
- **Kerem** und später **Hasan**: Content Creator. Arbeiten auf dem Branch `arbeit`.

## So fängst du an

1. Öffne in der Claude-Desktop-App einen neuen Code-Chat in diesem Ordner.
2. Füge den Text aus `wiki/prompts/wiki-chat.md` ein. Der Wiki-Chat begrüßt dich und erklärt alles Weitere.
3. Gearbeitet wird immer auf dem Branch `arbeit`, nie auf `main`. Claude prüft das beim Start.

## Was wo liegt

| Ordner | Inhalt |
|---|---|
| `wiki/` | Onboarding: acht Dokumente zum Einlesen, Start-Prompts für neue Chats |
| `marke/` | Produktfakten, Markenstil (Entwurf), Glossar DE/EN/TR |
| `content/` | Ideen, Produktion, Veröffentlichtes, Content-Kalender |
| `marketing/` | Kampagnen, Aufgaben, Warteliste |
| `journal/` | Testjournal, Kennzahlen je Woche, Wochenrückblicke |
| `inspiration/` | Hook-Bibliothek und Vorbilder |
| `feedback/` | Fan-Feedback, zusammengefasst und ohne Namen |
| `rechte/` | Freie Quellen und Liste nicht-freier Medien |
| `.claude/` | Einstellungen und Skills für Claude |

Videos, Bilder und Musik liegen nicht hier, sondern im OneDrive-Ordner „FootPulse Marketing“.

Die festen Regeln stehen in `CLAUDE.md`.
